# 12. エラー・例外処理

## 12.1 単語入力エラー

| 条件 | 表示例 | 処理 |
| --- | --- | --- |
| 空入力 | `単語を入力してください。` | フロントエンドで送信を阻止し、手番を維持する（確定ボタン非活性化等） |
| ひらがな・伸ばし棒以外を含む | `ひらがなと伸ばし棒で入力してください。` | フロントエンドで送信せず、手番を維持する |
| 接続不成立 | `前の単語の最後の文字から始まっていません。` | 無効入力として扱う |
| `ん`で終わる | `「ん」で終わる単語は使えません。` | 無効入力として扱う |
| 既出単語 | `この単語はすでに使われています。` | 無効入力として扱う |
| 文字数制限外 | `設定された文字数の範囲外です。` | 無効入力として扱う |

エラー表示は利用者入力をメッセージへ連結せず、固定文とする。無効入力の処理は初期設定の「ターンスキップ」または「失格」に従う。不正なリクエストにより空入力や対象外文字が直接送信された場合も、サーバーは400エラーで拒否し手番を維持する。

## 12.2 設定エラー

- ロビー参加者が2人未満の場合はゲーム開始を許可せず、2人以上の参加が必要であることを通知する。
- チーム戦で所属人数が0人のチームが存在する場合はゲーム開始を許可しない。
- カードサイズが空、数値以外、偶数、2以下、候補文字数から算出した上限超過の場合はゲーム開始を許可しない。
- ターン数が空、数値以外、0以下の場合はゲーム開始を許可せず、正の整数を求める。ビンゴ数は`1〜2N+2`の範囲外の場合にゲーム開始を許可しない。
- 参加時またはロビーでの名前変更で名前が空文字の場合は処理を拒否し、「名前を入力してください。」と表示する。重複、文字数、使用文字についてはエラーにしない。
- 終了条件に対応しない目標値は入力対象外とする。
- 最小文字数・最大文字数は未設定なら制限なしとし、1未満または最小値が最大値を超える設定は許可しない。

## 12.3 localStorageエラー

### 読み込み失敗

保存値がJSONとして解釈できない場合、または必要な型を満たさない場合は該当プリセットを読み込まず、初期値を使用する。

### 書き込み失敗

容量不足、プライベートブラウジング制限、ブラウザ設定などでプリセットの書き込みに失敗した場合は、ゲーム開始を妨げず、「プリセットを保存できませんでした。現在のゲームでは利用できます。」と表示する。

## 12.4 時間処理の例外

- タイマーが0秒未満にならないよう、表示値は0秒で下限を止める。
- 0秒到達だけでは手番を変更しない。
- ブラウザが一時停止して時間表示が飛んだ場合も、確定操作時の現在時刻で残り時間を再計算する。
- 時間計測中にundoした場合は、復元対象の手番の設定時間へリセットする。

## 12.5 undoエラー

undo対象がない場合、undoボタンを無効にする。状態が壊れてスナップショットを復元できない場合は、undoを拒否してサーバーに保存された現在状態を維持し、親へ復旧が必要であることを通知する。結果画面ではundoを受け付けない。

## 12.6 全員失格

すべてのプレイヤー（チーム戦では全チーム）が失格になった場合、現在のターンの終了を待たずに即時でゲームを終了し、結果画面を表示する。親が「ゲーム終了」を押した後に同じルームのロビーへ戻り、部屋と参加者を維持する。次のゲーム開始時にカードと失格状態を初期化する。

## 12.7 ページ再読み込み

専用URL（`/game/:roomId`）で再読み込みされた場合、再接続Cookieで同じプレイヤーとしてルームへの再接続を試み、サーバーの最新状態をSSEで受信する。Cookieがない場合や再接続期限を過ぎた場合は、名前を入力して新しい参加者として参加する。存在しないルームでは名前入力を表示せず、ルームが存在しない旨とトップページへ戻る操作を表示する。ルートURLでルームを作成する場合は、選択中または編集中の設定を使用する。
