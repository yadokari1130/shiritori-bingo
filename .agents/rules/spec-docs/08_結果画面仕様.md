# 8. ゲーム終了状態仕様

## 8.1 ロビー復帰タイミング

次のいずれかを満たしたときに終了状態をSSEで配信し、クライアントは結果画面を表示する。

- 指定ターン数が終了した（現在のターンの全手番を完了した時点）。
- 指定ビンゴ数を参加中プレイヤーまたはチームが達成した（現在のターンの全手番を完了した時点）。
- 個人戦で全プレイヤー、またはチーム戦で全チームが失格になった（最後のアクティブな手番対象が失格になった瞬間に即時終了）。

結果画面では、参加者や接続状態が変化しても結果画面用の確定スナップショットを保持する。親が「ゲーム終了」を押したときだけ同じルームを`setup`へ戻し、全クライアントをロビーへ遷移させる。

結果画面で切断した参加者は30分間再接続を受け付ける。30分を過ぎた参加者はルームの参加者から削除するが、結果画面に表示する確定済みの結果情報は親がロビーへ戻すまで保持する。

## 8.2 終了状態

終了状態には、個人戦では失格していないプレイヤー、チーム戦では失格していないチームの順位計算に必要な情報を含め、フロントエンドは順位画面として表示する。

| 表示項目 | 内容 |
| --- | --- |
| 順位 | ビンゴ数と開いたマス数で決めた順位（Standard Competition Ranking: 1224方式。同点の場合は同じ順位とし、次の順位は同順位の数だけスキップする） |
| プレイヤー名またはチーム | ロビーで登録された名前・所属をテキストとして表示。CPUプレイヤーの場合は `🤖 CPU` バッジを表示 |
| ビンゴ数 | 成立したビンゴ列の数 |
| 開いたマス数 | フリーマスを含む開放済みマス数 |
| 状態 | 通常または失格（失格者は順位欄に「失格」と表示） |

失格者は順位計算の対象外とし、全員が失格の場合は勝者なしとして扱う。

切断中のプレイヤーは、順位一覧とカード見出しのプレイヤー名の横に切断マークを表示する。チーム戦ではカード見出しに表示する所属メンバー名の横にも表示する。CPUプレイヤーは順位表およびカード見出しに 🤖 アイコン/バッジを表示する。

## 8.3 カード状況の終了時データ

個人戦ではプレイヤーごと、チーム戦ではチームごとに次の情報を終了時データとして保持する。

- プレイヤー名
- ビンゴ数
- 開いたマス数
- 失格状態
- 設定された`N×N`カードの全マス
- 開放済みマスの表示
- 成立済みビンゴ列の色・模様
- フリーマスの表示

カードの並び順は、対戦画面と同じしりとりの手番順とする。

## 8.4 開いた文字と単語履歴の終了時データ

終了状態には次を含める。

1. 有効単語を入力順に並べた単語履歴
2. 各単語を入力したプレイヤー
3. カードの清音候補および設定で有効にした追加文字を、5段の縦列グリッド（右から左へ並べる日本語の縦書き順）として文字開放状態表に表示する
4. 文字開放状態表の列配置は、右から順にあ行〜わ行の清音、が行〜ば行の濁音、ぱ行の半濁音、小さいあ行、特殊文字（ゃゅょっー）の順とする（設定で無効なカテゴリの列は除外する）。各列の5段は次の通り配置する（存在しないマスは「＿」の空枠とする）：

```text
ゃ ぁ ぱ ば だ ざ が わ ら や ま は な た さ か あ
ゅ ぃ ぴ び ぢ じ ぎ ＿ り ＿ み ひ に ち し き い
ょ ぅ ぷ ぶ づ ず ぐ ＿ る ゆ む ふ ぬ つ す く う
っ ぇ ぺ べ で ぜ げ ＿ れ ＿ め へ ね て せ け え
ー ぉ ぽ ぼ ど ぞ ご ＿ ろ よ も ほ の と そ こ お
```

5. 各文字を開放済み・未開放の2値で表示する。カードなし・フリーマスは開放状態の値として区別せず、フリーマスは開始時から開放済みとして扱う

無効入力は有効単語履歴と文字開放状態表の開放状態へ影響させない。フリーマスはゲーム開始時から開放済みとして扱う。

## 8.5 終了理由

終了状態には次の終了情報を含める。

- 選択された終了条件
- 終了したターン番号
- 指定ビンゴ数で終了した場合は達成者
- 全員失格で終了した場合はその旨

## 8.6 ロビー復帰と再戦

終了状態を受信したクライアントは結果画面を表示する。親が「ゲーム終了」を押すと、同じルームのロビーへ遷移する。ロビー復帰時はルームを破棄せず、「ゲームを開始」から次のゲームを開始する。選択中の設定プリセットまたはロビーで変更した設定を使用し、カード、手番順、フリーマス、単語履歴は新規生成する。

結果画面の「ゲーム終了」は親だけが操作でき、参加者は親の操作を待つ。

結果画面ではundoを実行できない。undoボタンは表示せず、結果状態でのundoリクエストはサーバーが拒否する。
