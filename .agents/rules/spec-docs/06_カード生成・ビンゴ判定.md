# 6. カード生成・ビンゴ判定

## 6.1 カード構成

- カードは設定値`N`による`N`行`N`列の`N×N`マスとする。`N`は3以上の奇数で、初期値は5とする。
- 座標は0始まりの行・列で管理し、中央は`(floor(N / 2), floor(N / 2))`とする。
- 中央マスをフリーマスとする。
- フリーマスの文字は清音候補からゲーム開始時に1文字ランダムに選ぶ。
- 全プレイヤーの中央マスには同じ文字を設定する。
- フリーマスはゲーム開始時から開いている。
- 中央以外の`N×N - 1`マスは、プレイヤーごとに独立してランダム生成する。
- フリーマスを含め、同じカード内では文字を重複させない。
- プレイヤー間のカードでは、同じ文字の重複を許可する。
- 有効な文字候補数が`N×N`未満になる設定では、カードを生成できないためゲームを開始できない。
- カードサイズの上限は、有効な文字候補数を`M`としたとき、`N×N <= M`を満たす最大の奇数`N`とする。
- 個人戦ではプレイヤーごとに1枚、チーム戦ではチームごとに1枚のカードを生成する。

## 6.2 清音候補

フリーマスとカードの基本候補は次の清音とする。

```text
あいうえお
かきくけこ
さしすせそ
たちつてと
なにぬねの
はひふへほ
まみむめも
やゆよ
らりるれろ
わ
```

`ん・ゐ・ゑ・ゔ・を`は、フリーマス候補にもカード候補にも含めない。

## 6.3 オプション文字候補

設定が有効なカテゴリだけを、基本の清音候補へ追加する。

| カテゴリ | 文字 |
| --- | --- |
| 拗音 | `ゃゅょ` |
| 促音 | `っ` |
| 伸ばし棒 | `ー` |
| 小さいあ行 | `ぁぃぅぇぉ` |
| 濁音 | `がぎぐげござじずぜぞだぢづでどばびぶべぼ` |
| 半濁音 | `ぱぴぷぺぽ` |

`ゔ`は濁音カテゴリを有効にしても含めない。設定で除外されたカテゴリの文字はカードに存在しないだけで、入力や語尾処理から除外しない。

## 6.4 文字開放

有効単語を確定したら、単語を文字単位に分解し、各カードのマス文字と完全一致するマスを開く。

- 濁音、半濁音、清音を別文字として比較する。
- 拗音は組み合わせではなく、`きゃ`なら`き`と`ゃ`として扱う。
- 同じカード内の文字は重複しないため、入力文字に一致するマスをカードごとに最大1つ開く。
- 文字がカード候補に含まれていなければ、どのマスも開かない。
- 1単語による開放で複数のビンゴ列が同時に成立する場合、すべて成立させる。
- 一度開いたマスは、undoを除いて閉じない。

## 6.5 ビンゴ列

`N×N`カードの次の`2N+2`列をビンゴ対象とする。

- 横`N`列
- 縦`N`列
- 左上から右下の斜め1列
- 右上から左下の斜め1列

各列は、`N`マスすべての`isOpen`が真になった時点で成立する。成立済みの列は識別子で管理し、同じ列を再度加算しない。成立した列は対戦画面で色を変えて表示する。

## 6.6 ビンゴ数と開いたマス数

- ビンゴ数は成立列の数である。
- 開いたマス数は`isOpen`が真のマス数である。
- フリーマスは開始時から開いているため、開いたマス数に含める。
- ビンゴ数と開いたマス数はプレイヤーごとに集計する。
- 失格したプレイヤーまたはチームのカードも単語による開放を受けるが、順位とビンゴ終了条件の対象からは除外する。

## 6.7 リーチマス

未開放マスを仮に開いてビンゴ列を再計算し、まだ成立していないビンゴ列が1列以上成立するマスをリーチマスとする。複数のビンゴ列を同時に成立させるマスには、リーチ強調用の状態を付ける。成立済みのビンゴ列だけを完成させるマスはリーチマスに含めない。

リーチマスとリーチ強調状態はカード状態から都度再計算し、サーバーのゲーム状態に保存する必要はない。対戦画面では未開放状態を維持したまま表示する。

## 6.8 開放対象のプレビュー

対戦画面で現在の手番プレイヤーが単語を入力している間、現在のカード内で入力文字に完全一致する未開放マスをプレビュー状態としてハイライトする。確定前のプレビューはゲーム状態を変更しない。無効入力を確定した場合はプレビューを破棄する。
