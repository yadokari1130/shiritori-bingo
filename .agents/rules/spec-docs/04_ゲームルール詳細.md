# 4. ゲームルール詳細

## 4.0 対戦モード

対戦モードは個人戦とチーム戦から1つ選択する。個人戦ではプレイヤーごとにカードを1枚生成し、プレイヤーが手番、順位、ビンゴ数、失格状態の単位になる。チーム戦では設定したチーム数のチームを作り、チームごとにカードを1枚生成する。チーム戦ではカード、手番、順位、ビンゴ数、終了条件、失格状態の単位はチームであり、プレイヤー個人には設定しない。

チーム戦のチーム所属者は、チームの手番中であれば誰でも単語を入力して確定できる。チームの手番中に入力できるのは現在のチームの所属者だけであり、他チームの所属者は表示のみとする。

## 4.1 ゲーム開始

カードサイズは初期設定で指定された3以上の奇数`N`とし、カードは`N×N`で生成する。初期値は`N=5`である。中央座標は`(floor(N / 2), floor(N / 2))`とする。

1. 初期設定を確定する。
2. 清音候補からフリーマス用の文字を1文字ランダムに選ぶ。
3. 個人戦では全プレイヤー、チーム戦では全チームに同じフリーマス文字を持つカードを生成する。
4. プレイヤーをランダムに並べ、ゲーム中の手番順として固定する。
5. 1ターン目の1人目を現在プレイヤーにする。
6. 最初の開始文字をフリーマス文字にする。
4. プレイヤーをランダムに並べ、ゲーム中の手番順として固定する。
5. 1ターン目の1人目を現在プレイヤーにする。
6. 最初の開始文字をフリーマス文字にする。
7. 1ターン目の1人目だけ、通常の制限時間にエクストラタイムを加える。

最初の単語も、フリーマス文字と同じ濁点グループに属する文字（同一文字または濁点・半濁点の付け外し）から始めることができる。

## 4.2 入力文字

入力欄では文字種を制限せず、カタカナ、漢字、英数字、絵文字、空白、句読点なども入力できる。確定時にフロントエンドが入力内容を検査し、空文字（0文字）またはひらがなと伸ばし棒`ー`以外を含む入力はサーバーへ送信せず、手番も消化しない。伸ばし棒は、カード文字設定で無効にしていても入力できる。サーバーも同じ形式検査を行い、空文字や不正文字を含む直接送信を拒否して手番を維持する。

エクストラ設定で最小文字数または最大文字数を指定した場合、入力単語の文字数が設定範囲外ならゲームルール上の無効入力とする。最小・最大文字数は境界値を含み、未設定は制限なしとする。文字数制限による無効入力は、設定されたターンスキップまたは失格を適用する。

カード文字設定で除外した文字も、入力には使用できる。設定はカードの文字候補だけに影響し、入力文字の許可範囲やしりとりの語尾処理には影響しない。

`ん`は単語途中では使用できるが、単語の有効な語尾が`ん`になる単語は無効とする。単語は1文字以上必要とする。

## 4.3 しりとりの接続判定

### 4.3.1 基本判定

2語目以降は、直前の有効単語から求めた現在の開始文字で始まらなければならない。入力単語の最初の文字が開始文字候補に含まれる場合を接続成立とする。

単語の存在確認は行わない。入力文字、接続、語尾、重複だけを判定する。

### 4.3.2 濁点・半濁点

直前の語尾と入力単語の最初の文字は、同じ濁点グループに属していれば接続できる。カードの開閉ではこの緩和を行わず、文字を完全一致させる。

| グループ | 同一扱いにする文字 |
| --- | --- |
| か行 | か・が、き・ぎ、く・ぐ、け・げ、こ・ご |
| さ行 | さ・ざ、し・じ、す・ず、せ・ぜ、そ・ぞ |
| た行 | た・だ、ち・ぢ、つ・づ、て・で、と・ど |
| は行 | は・ば・ぱ、ひ・び・ぴ、ふ・ぶ・ぷ、へ・べ・ぺ、ほ・ぼ・ぽ |
| う | う・ゔ |

例えば、`くいず`の次に`すいか`、その次に`がす`を入力できる。`がす`の入力によって開くのは`が`と`す`であり、`か`は開かない。

### 4.3.3 語尾の正規化

直前の単語の語尾は、次の順に処理する。

1. 語尾が`ん`なら無効とする。
2. 連続する伸ばし棒`ー`や特殊文字は、末尾からさかのぼって最初に出現する文字を探索する。
3. さかのぼって見つかった文字が拗音の`ゃ・ゅ・ょ`なら、`や・ゆ・よ`として扱う。
4. さかのぼって見つかった文字が促音の`っ`なら、`つ`として扱う。
5. さかのぼって見つかった文字が小さいあ行の`ぁ・ぃ・ぅ・ぇ・ぉ`なら、`あ・い・う・え・お`として扱う。
6. それ以外の通常文字なら、その文字をそのまま扱う。
7. 末尾からさかのぼっても有効な通常文字や直音変換可能な文字が存在しない場合（例: `ーー`、`っっ`など）は無効とする。

正規化後の語尾が`ん`になる場合（例: `んー`）も、次の単語を継続できないため無効とする。

例:

| 直前の単語 | 次の開始文字 |
| --- | --- |
| `しりとり` | `り` |
| `きしゃ` | `や` |
| `ぎたー` | `た` |
| `らーー` | `ら` |
| `きょーー` | `よ` |
| `きゃっ` | `つ` |
| `まぁ` | `あ` |

### 4.3.4 最初の単語

最初の単語も、フリーマスに表示された清音と同じ濁点グループに属する文字から始めることができる（濁点・半濁点の付け外しが可能）。語尾の処理は通常の有効単語と同じように行う。

## 4.4 単語の重複

同じゲーム内で一度有効になった単語は再使用できない。既出単語と完全一致する入力は無効とし、無効入力の設定に従ってターンスキップまたは失格にする。

無効入力は単語履歴、開放処理、開始文字の変更を発生させない。ただし、現在プレイヤーの手番は終了する。

## 4.5 単語によるマス開放

有効単語を確定すると、単語に含まれる各文字と完全一致するマスを、ゲームに存在するすべてのカードから開く。失格者または失格チームのカードも含め、すべてのカードへ同じ開放処理を適用する。

- 同じカード内の文字は重複しないため、入力文字に一致するマスをカードごとに最大1つ開く。
- 既に開いているマスの状態は変わらない。
- 濁音・半濁音と清音は別文字として比較する。
- 設定でカードに含めなかった文字は、カードに存在しないため開放結果を生まない。
- `かーど`では、カードに存在する`か`、`ー`、`ど`だけが開き、`と`は開かない。

有効単語の文字は、入力された文字単位で扱う。例えば、拗音を含む`きゃ`は`き`と`ゃ`の2文字として扱う。

## 4.6 ターンと手番

1ターンは、ターン開始時点で参加中のプレイヤーが、固定された手番順に1回ずつ手番を終えるまでとする。単語を有効に確定した場合、ターンスキップした場合、失格になった場合のいずれも、そのプレイヤーの手番を消化したものとする。

ターン開始時に、そのターンの手番対象を固定する。ターン中に失格になったプレイヤーは、その手番を終えた後、次のターン以降の対象から除外する。手番順の並び自体は変更しない。

有効単語がない場合、現在の開始文字は変わらない。ターンスキップまたは失格の後は、次の対象プレイヤーが同じ開始文字に対して入力する。

チーム戦では、上記のプレイヤーをチームに読み替える。1ターン開始時点のチーム順を固定し、チームの所属者のうち最初に確定した1人を入力者として履歴に記録する。チーム内の入力者が変わっても、チームの手番位置は変わらない。入力者は履歴上の識別情報としてのみ記録し、カード、順位、ビンゴ数、失格状態はチーム単位で管理する。

## 4.7 制限時間

- 制限時間はプレイヤーごとの手番開始時に開始する。
- 通常の制限時間は初期値30秒とする。
- 1ターン目の1人目だけ、初期値10秒のエクストラタイムを加える。
- エクストラタイムはゲーム全体で最初の1手番だけに適用する。
- 「時間切れ時に強制スキップ」が無効なら、残り時間が0秒になっても自動失格、自動スキップ、入力欄のロックは行わない。0秒表示後も手番を継続する。
- 同設定が有効なら、残り時間が0秒になった時点で入力欄をロックし、強制スキップを1回だけ適用して次の手番へ進む。入力途中の単語は破棄する。
- undoを実行した場合、復元された手番の制限時間を、その手番の開始時設定値へリセットする。1ターン目の1人目を復元した場合は、エクストラタイムを含む時間へリセットする。

## 4.8 無効入力

すべてのゲームルール上の無効判定（しりとり接続不成立、語尾が`ん`、既出単語、文字数制限外）はバックエンドで一元的に判定する。

空文字やひらがな・伸ばし棒以外を含む入力は、常にフロントエンドで送信を阻止し、手番を消化しない（サーバーでも不正な形式を400エラーで拒否し手番を維持する）。

エクストラ設定の「入力文字チェック」の設定に応じて、送信前の挙動が変化する。
- **入力文字チェックが有効（デフォルト）**: フロントエンドでもルール条件（しりとり接続、語尾「ん」、既出単語、文字数制限）を検証し、無効な単語の送信を阻止する（手番は消化しない）。
- **入力文字チェックが無効**: フロントエンドでは空文字およびひらがな・伸ばし棒以外のみ送信を阻止し、ルール上の無効単語（接続不一致、既出単語、「ん」終わり等）の送信を許可する。サーバーへ送信された無効単語は、設定（ターンスキップまたは失格）に従って即座に処理され、手番を消化する。単語の存在確認は無効入力の判定に含めない。

### ターンスキップ

- 現在の開始文字を維持する。
- カードを開かない。
- 単語履歴へ追加しない。
- 現在プレイヤーの手番を消化する。
- 次の手番へ進む。

### 失格

- 現在の開始文字を維持する。
- カードを開かない。
- 単語履歴へ追加しない。
- 現在プレイヤーの手番を消化する。
- 個人戦ではプレイヤーを、チーム戦ではチームを失格状態にし、次のターン以降の手番から除外する。
- ゲーム終了後にロビーへ戻った後も、失格状態は次のゲーム開始時に初期化する。

初期設定の無効入力はターンスキップとする。

### 4.8.1 リーチ判定

各カードについて、未開放マスを1つ仮に開いた状態でビンゴ列を判定する。その結果、新たに成立するビンゴ列が1列以上ある未開放マスをリーチマスとする。すでにビンゴ列が成立している列はリーチ判定に使用しない。

1つの未開放マスで複数の未成立ビンゴ列が成立する場合、そのマスはリーチ強調の対象とする。リーチ状況は入力や確定の有無にかかわらず、最新のカード状態から再計算する。

## 4.9 終了条件

終了条件は初期設定で次のどちらか一方を選択する。

### 指定ターン数

指定したターン数が終了した時点で、現在のターンの処理を完了し、結果画面を表示する。初期値は3ターンとする。

### 指定ビンゴ数

個人戦ではいずれかの参加中プレイヤー、チーム戦ではいずれかの参加中チームが指定ビンゴ数に到達したターンの終了時に、結果画面を表示する。ビンゴ数はターン途中では終了判定せず、現在のターンに含まれる全手番を処理してから判定する。初期値は3ビンゴとし、設定可能な上限は`2N+2`とする。

失格したプレイヤーまたは失格したチームのカードが指定ビンゴ数に到達しても、終了条件の達成者には含めない。

### 全員失格

個人戦では全プレイヤー、チーム戦では全チームが失格になった場合は、現在のターンの終了を待たずに即時でゲームを終了し、結果画面を表示する。

結果画面で親が「ゲーム終了」を押すと、同じルームのロビーへ戻る。

## 4.10 順位

個人戦では失格していないプレイヤーを、チーム戦では失格していないチームを、次の順で比較する。

1. ビンゴ数が多い順
2. 開いたマス数が多い順
3. 上記が同じ場合は同順位

順位付けには Standard Competition Ranking（標準競技順位: 1224方式）を採用する。同順位が存在する場合、次の順位は同順位の数だけスキップする（例: 1位が2人存在する場合、次の順位は3位となり、2位は存在しない）。

失格者は順位計算の対象外とし、順位欄には「失格」と表示する。

ビンゴ数は成立した横`N`列、縦`N`列、斜め2列をそれぞれ1列として数える。フリーマスが開いているため、フリーマスを含む列はゲーム開始時から判定対象になる。

## 4.11 CPUプレイヤーの行動・思考

CPUプレイヤーは、サーバーに内蔵された辞書データ（約6万語の名詞辞書）および盤面評価エンジンによって動作する。

1. **候補単語の抽出**: 現在の開始文字に接続し、文字数制限を満たし、既出単語を除いた有効単語を抽出する。
2. **1手先盤面評価（スコアリング）**:
   - 自分のカードの新規ビンゴ成立数（+1000点/本）
   - 自分のカードの新規リーチ作成数（+100点/本）
   - 自分のカードの新規開放マス数（+10点/マス）
   - 語尾の返しにくさ・攻撃力（最大+50点）
   - 次手番プレイヤーの妨害・手詰まり化ボーナス（+30点）
   - 他プレイヤー・チームへの利敵減点
3. **最善手の確定**: 最もスコアの高い単語を選択し、演出のための思考ウェイト（約1秒）を挟んだ後に自動確定する。有効な単語がない場合はスキップする。

## 4.12 補助モード（アシスト機能）

プレイヤーが対戦中に「補助モード」を有効にした場合、手番プレイヤーに対して内蔵辞書からルール上有効かつ評価スコアの高い上位単語候補からランダムにサンプリング（最大3件）して提示する。プレイヤーは提示された単語チップをクリックすることで入力欄にセットできる。
