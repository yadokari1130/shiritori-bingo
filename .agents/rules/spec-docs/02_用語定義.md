# 2. 用語定義

| 用語 | 定義 |
| --- | --- |
| 親 | ロビーでルールを設定してゲームを開始し、undoなどを操作する利用者 |
| プレイヤー | ゲームに参加する利用者。個人戦ではカード、手番、順位、ビンゴ数、失格状態の単位になり、チーム戦では名前、所属、接続状態、入力者識別の単位としてチームに所属する |
| チーム | チーム戦で複数の参加者と1枚のビンゴカードを共有する単位 |
| チームメンバー | チームに所属するプレイヤー。チームの手番中は誰でも入力できる |
| ゲーム | ロビーから終了して同じロビーへ戻るまでの1回の対戦 |
| 手番 | 1人のプレイヤーが単語を入力または無効入力として処理する機会 |
| ターン | 開始時点で参加中のプレイヤーが、手番順に1回ずつ手番を終える単位 |
| 手番順 | ゲーム開始時にランダムに決まり、ゲーム中は変わらないプレイヤー順 |
| チーム手番 | チーム戦で1チームが単語を入力または無効入力として処理する機会 |
| 現在の開始文字 | 現在の単語が開始すべき文字。最初はフリーマスの文字 |
| 単語 | 手番のプレイヤーが入力して確定するひらがな列。単語の存在確認は行わない |
| 有効単語 | 文字形式、重複、しりとり接続、語尾のルールを満たし、ゲーム状態を更新する単語 |
| 無効入力 | 有効単語にならない入力。設定によりターンスキップまたは失格になる |
| カード | プレイヤーに割り当てられる奇数サイズのN×Nビンゴ盤 |
| マス | カード上の1つの文字セル |
| フリーマス | カード中央のマス。全員が同じ清音を持ち、ゲーム開始時から開いている |
| 開く | マスの`isOpen`状態を未開放から開放へ変更すること。一度開いたマスは閉じない |
| 開いたマス数 | 個人戦ではプレイヤーのカード、チーム戦ではチームのカードで`isOpen`が真であるマスの数。フリーマスを含む |
| ビンゴ列 | Nマスすべてが開いた横列、縦列、または斜め列 |
| ビンゴ数 | 個人戦ではプレイヤーのカード、チーム戦ではチームのカードで成立しているビンゴ列の数。同じ列は1回だけ数える |
| リーチマス | 未開放であり、そのマスを開けばビンゴ列が成立するマス |
| リーチ強調 | 1つのマスで複数のビンゴ列を同時に成立できる場合に追加で目立たせる表示 |
| リーチマス | 未開放であり、そのマスを開けばビンゴ列が成立するマス |
| リーチ強調 | 1つのマスで複数のビンゴ列を同時に成立できる場合に追加で目立たせる表示 |
| 失格 | 無効入力の扱いとして選択された場合に、以降の手番から除外された状態 |
| ターンスキップ | 無効入力の扱いとして選択された場合に、カードとしりとり状態を変えず手番だけ終える処理 |
| 強制スキップ | 制限時間到達時に設定が有効なら、入力なしでカードとしりとり状態を変えず手番を終える処理 |
| 文字候補 | カードの中央以外のマスにランダム配置する文字の集合 |
| 直音 | 拗音、促音、小さいあ行を通常の大きさのかなへ変換した文字 |
| 語尾正規化 | 単語の末尾から、伸ばし棒、拗音、促音、小さいあ行を処理して次の開始文字を求める処理 |
| 文字開放状態表 | カード候補の文字をあいうえお表と追加文字の区分で表示し、開放済み・未開放の2値を確認できる表。カードなしやフリーマスは開放状態の値として区別しない |
| undo | 直前の確定操作を取り消し、操作前のゲーム状態へ戻したうえで復元対象の手番の制限時間を開始時設定へリセットする処理 |
| CPUプレイヤー | 人間の代わりにサーバーの思考エンジンによって自律的に単語を選択・入力する仮想プレイヤー |
| 補助モード（アシスト機能） | 対戦中にプレイヤーの手番を支援するため、内蔵辞書からルール上有効かつ戦術的に有利な単語候補をサンプリング提案する機能 |
